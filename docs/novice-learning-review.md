# 从零开始的学习流程改造

2026-11-04。沿用当前网站主题与课程 ID，围绕第一次进站、第一次作答、第一次输入命令进行改造。

## 已改内容

- 首页增加零基础入口；指南说明选课、输入、执行、验证、确认、回看、继续学习，以及手机与电脑的差别。
- 全部通用分步课堂显示学前准备、学习目标、当前动作与通关条件。其他独立模块保留原有流程。
- 重写最前面的电脑、终端两课，避免在尚未理解命令输入前提前堆入 UID、sudo 等后续内容。
- 13 节常用命令起步课改为 4 页：目标、逐段用法、输入与输出对照、常见错误。其默认示例输出由既有教学模拟器生成。
- 13 节命令课与电脑第一课使用具体场景小测。命令课不再重复同一个泛泛问题；电脑课小测也与前面的操作题区分。
- 对旧版小测采用 assessment revision 校验，防止原题选项序号碰巧相同就自动通过新题。保留阅读、草稿、文件快照和已确认步骤，只要求重答有改动的小测；其他题的记录不受影响。
- 增加管道分步演示，可查看原文、筛选和计数，切换 ERROR / INFO / WARN；结果通过同一个教学模拟器计算。演示不会修改练习完成状态。
- 补细页面请求取证、应用日志关联、DM8 精确查询三课。说明证据与推断的区别，明确路径来自固定教学环境。请求卡不虚构缺失时间：现有简化访问日志未包含时间字段。
- 实操选择题先作答后解释；未选时检查按钮禁用。错误反馈带选项、原因与保留进度的回看入口。命令错误增加提示符、全角符号、把返回值当命令、`-l` / `-1`、管道右侧重复读取文件等提示。
- 统一运维推荐顺序、关卡编号、下一课预告与 Next 动作，去掉独立的捕获阶段 Next 实现。物理数组及稳定 ID 保持兼容。
- 修复实际走课发现的异常：最后一个操作确认后输入框已消失，原 render 仍访问其 value，导致后续课堂装饰和指引中断。现先检查输入框是否存在。

## 教学和技术参考

- [Software Carpentry / The Unix Shell](https://swcarpentry.github.io/shell-novice/)：参考学前问题、明确目标、示例与独立练习相接的组织方式。
- [黑马程序员 Linux 公开大纲](https://www.itheima.com/special/linuxzly/)：参考系统基础、网络服务、数据库、自动化与容器的主题范围。没有复制付费讲义，也不代表获得机构审核。
- [GNU Bash](https://www.gnu.org/software/bash/manual/)、[Coreutils](https://www.gnu.org/software/coreutils/manual/)、[grep](https://www.gnu.org/software/grep/manual/)：命令含义与边界参考。中文讲解、场景和题目为本站原创。
- 现有 DM8 课程引用达梦官方文档；本次沿用既有模拟器与查询样本，未宣称接入实际数据库。
