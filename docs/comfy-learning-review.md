# ComfyUI 学习区交付记录

## 当前范围

35 节原创课程、七个阶段。首版 25 课保留稳定 ID；新增 10 节工作流实战：有效分支、音乐、素材分段、音画 latent 二采、双历史归档、音轨时钟、媒体类型、动作参考、提示词与硬约束、版本迁移。每课有先备、目标、关系示例、操作判断和独立小测。

五份结构示例：四份公开上游工作流的字段白名单教学版，加一份本站原创 9 节点 / 10 连接的音乐图。全部没有提示词、控件值、素材引用或附加元数据；不能直接用于生成。来源、上游版本与许可见 dist/data/comfy/NOTICE.md。

节点解释新增音乐、联合 AV 分离合并、T8 二采协调、素材分段、双 Picker / Saver、学习型放大器与文件封装。SaveAudioAdvanced 的 AUDIO 透传和 VideoCombineV2 的 VHS_FILENAMES 依据公开定义说明，不把所有保存节点说成没有输出。节点详情显示 mode 2 / 4 与常规状态，子图虚拟边界有独立解释；静态图仍不当作执行日志。

## 来源与边界

授权补充资料仅用于本轮静态核对。部分内容读取失败，未据其文件名编造内部连线；私人目录清单、网盘 FID、原始 JSON、提示词模板、素材引用和账号状态都不进入公共仓库。公开课程与音乐结构图独立编写，接口说明对照 Core、ClipStream、H3 Long Video Manager、T8、Easy 和 FeiHou 原项目。每课与节点保留公开来源。

两个 b23 合集的完整分集目录和字幕仍未取得。此前核对的六条公开视频仅为简介入口，不是完整视频提取。未把推测作者关系当作已确认身份。

解析器支持本地界面 / API JSON、子图、端点、槽位、联合类型与拓扑提示；未知 class_type 保留端口并明确未核实。完整 JSON 仅在浏览器内存处理，刷新需重导；不上传、不安装节点、不下载权重、不连接本地 ComfyUI、不运行 GPU。模型兼容性、隐藏依赖、缓存、效果与资源峰值需在真实环境另行验证。

## 验证

新增与保留的 tests/comfy.cjs 覆盖五份结构版的字段白名单、界面 / API 格式、对象连线、子图边界、类型、悬空端点、依赖环、大小上限、未知节点、转义、帧数计算，及全部 35 课的错误答案阻止、显式确认、手动前进和保存恢复；检查课程来源与示例引用完整、原创示例说明不出现 undefined。

通用 hub 回归为 326 课 / 583 操作，原零基础流程另行检查。它们是 DOM / 状态测试，不能称为全部课程的真实浏览器验收。

本轮浏览器检查覆盖 35 课路线、新实战阶段、音乐节点与 seconds / 音频 latent 连线、原创来源说明和新课阅读与操作门禁。页面沿用既有字体与中性 / 青绿主题；没有更换框架。新 UI 静态风格检查 0 FAIL / 0 WARN。使用受控浏览器检查；没有运行另起浏览器的 inspect.mjs，未实际模拟手机。移动排版沿用原单列 / 独立滚动规则。
