# ComfyUI 学习区交付记录

2026-11-04。保留运维主线和既有页面主题，新增独立 ComfyUI 导航入口。

## 范围

- 25 节原创课程、六个阶段：认识节点、生图原理、控制与复现、从图到视频、H3 与接续、独立排障。每课包含目标、先备、概念、关系示例、操作判断与独立小测。
- 复用阅读 → 验证操作 → 手动确认 → 小测 → 手动下一课。错误答案阻止通过，不自动跳课，课程进度独立保存。
- 四份公开工作流的教学结构版：SDXL、Wan 2.2 5B、H3 I2V、ClipStream。主图 / 内部节点分别为 7/0、12/0、6/21、36/22；子图边界单列。全部提示词、控件值、素材引用、便签和附加元数据已删除，不能直接用于生成。
- 节点职责、端口类型、上下游、点击连线解释、子图展开、依赖追踪、同名 Set / Get 候选。结构版没有中转变量值，只有本地完整原文件能检查其名称。
- 本地导入界面 JSON 或 API prompt JSON。未知自定义节点、缺失签名明确标为未知；不会按名称编造功能。解析端点、槽位、联合类型和拓扑；不把子图级回接直接等同于实际执行环。
- 连线类型练习、帧数 / fps / 模型网格计算器、九类排障提示。编辑参数后必须重新计算；演示不改变课程通过状态。
- 六条已核对公开简介的视频入口、25 个原创课程主题、七个配套开源项目入口与来源核对状态。

## 材料与隐私边界

用户提供的两个 b23 短链返回访问错误，未取得当前完整合集目录和字幕；视频状态仅为核对公开简介。未确认的作者与合集不擅自合并身份。用户网盘工作流尚无可读取的明确分享链接或目录位置，本轮没有访问其私存版本。

首次发布检查阻止了包含完整上游 JSON 的提交。随后改为严格字段白名单的教学结构版，并删除历史提取索引；公开主题全部从原创课程派生。回归测试检查公开示例不含控件值、提示词、模型文件名、素材 URL、便签或附加元数据。原始来源、上游版本和许可见 dist/data/comfy/NOTICE.md。

用户完整工作流只在当前浏览器内存中解析，不上传、不持久保存；刷新需重新导入。本站不执行生成、不安装节点、不下载权重、不连接本地 ComfyUI。
