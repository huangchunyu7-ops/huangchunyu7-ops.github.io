# 考公刷题模块

以原站点导航、色彩、字体和课程切换器扩展独立刷题区，保留运维主线。公开阅读入口为原站点的 `#civil`。

## 数据与边界

- 内置289道本站原创训练题，明确标注非历年真题：原有88题、177道识别／应用／边界分层题，以及24道具体变式应用。59张原创方法卡覆盖基础、熟练、进阶，包含适用条件、标准过程、快解、误区和配套题；题量包含识别与条件辨析，不能等同于289道实战难度真题。
- `data/civil/catalog.json` 来自 ERRRC/xingcezhenti 的公开文件树，抓取日期2026-10-27。515 个试卷标题对应2956篇模块笔记；58,890是上游声明的总题数，不能与当前设备已载入量混淆。
- 未将无单独再分发许可的上游整库打包。用户点击所选试卷后由浏览器按需读取原 Markdown 与图片；亦支持用户导入 MD / JSON / ZIP / 文件夹。保留 qid、原卷、模块、来源路径与解析；源数据没有可识别答案时标为待核。
- 真题解析按原仓库提供，不冒称本站已逐题核验或获得培训机构授权。不镜像老师付费课程、讲义和账号数据；不连接第三方 AI。教师相关社区笔记与教师本人页面分开标记，“高阳”未与“高照”混同。
- 题目缓存于 IndexedDB，进度、收藏、错因、历史和方法阅读记录在当前浏览器保存。导出备份包含相关题目与学习记录。清除站点数据会移除本地记录，暂不跨设备同步。自行导入的图片只在当前页面会话使用。

## 状态机

1. 选项变化只保存选择，不提交、不跳题。
2. 练习模式明确提交后锁定本次答案，显示解析。错题计数只记一次；重做为新的独立尝试。
3. 多选按集合全等判断，不给部分分。
4. 限时模式交卷前隐藏正确答案、解析和答题卡对错；允许修改已选答案。使用绝对截止时间，刷新与离开页面不延长倒计时。
5. 交卷弹层显示未选题数，确认后锁定整次答案并生成等权题目统计。它不是官方行测分数或预测分。
6. 练习暂停、关闭页面和离开答题页不计用时；提交后的解析阅读不计该题独立作答用时。恢复时重新确认继续。
7. 替换未完成练习时先提示，原记录保留在历史中。已提交结果不重复加入累计统计。
8. 当前错题以最近一次独立作答结果为准，历史错误数保留。SM-2风格复习排程采用1天、6天及后续加权间隔；它是辅助复习提示，不是记忆效果保证。

## 解析与安全

Markdown 解析支持二至四级题目标题，材料与随后小题绑定；编号即使在材料内重置，也从该题实际标题提取 qid。材料组抽样不拆散，实际题量可略多于用户指定。

题面 HTML 通过允许列表重新构建；不复制脚本、样式、事件属性、表单、框架和可执行链接。图片仅接受题库目录中的栅格路径，或用户本次导入的本地 Blob；图形、公式加载失败有明确提示。ZIP、条目数量、解压体积和单文件均有限制。导入 JSON 及备份检查基本字段和保留对象名，不安装或执行来源仓库代码。

## 分层路线与方法关联（2026-10-27）

六个行测模块分别提供基础识别、同类巩固、变式与边界、混合限时、真题迁移五阶段。前两阶段逐题练习，后续限时统一交卷；完成全部题且正确率至少80%后凭本次学习证据解锁。按钮不会自动跳阶段，已通过阶段可重练。真题迁移仅使用本设备明确答案、无待核标记的已载入真题，题量不足时跳到原卷目录，不拿原创题假充。80%是本站练习门槛，不是官方考试评分标准。

每张方法卡增加独立助记、使用条件、先备知识、引导例题、反例、三层训练和独立混合小测；阅读状态与测验通过分开。口诀页支持方法名、助记、公式和常见别名检索，并列出10种容易误用的“秒杀说法”及反例。假设分配、份数等社区名称仅作索引，数学推导和例子由本站独立编写，不将来源错误符号或速度承诺照搬。

训练默认按本站原创难度排序，原卷保留源顺序，材料组不拆分。未给全量真题伪造难度。解析中的方法关联分为原创配套、个人手动标注、未逐题核验的题型建议和待标注；题型规则不是生成的真题快解。个人可以保存本题关联和推导笔记，原解析独立保留。学习报告公开展示本设备关联覆盖数量及未关联真题入口。学习路线与标注包含在原有备份中；当前仍无跨设备自动同步。

`node tests/civil-path.cjs` 检查59类方法与289题、分层覆盖、六科各阶段失败与通过证据、真题来源要求、手动继续、独立小测、方法标注优先级、材料排序和备份恢复。基线 `civil.cjs` 仍单独验证原有88题／29方法兼容性。运维相关引擎、命令变体、课程、恢复与分页回归全部通过。浏览器实测覆盖错选后仍停留原题、方法回看、415别名检索，以及390px宽度下的路线与方法页面；这不是全库逐题核验或真实手机硬件测试。
